1. EXECUTIVE SUMMARY
--------------------------------================--------------------------------
Inventria is an enterprise-grade Smart Inventory & Warehouse Management Platform designed
to streamline operations across products, warehouses, suppliers, customers, purchase
orders, sales orders, analytics, and security configuration.

The project is structured with a modern single-page application (SPA) frontend in React 19,
Vite, and Tailwind CSS (v4) inside `frontend/`, designed for seamless integration with
the Spring Boot REST API backend (`com.inventria:inventria-api`) using PostgreSQL and Spring Security.

App Modules & Pages Functional Breakdown:
1. Login Page        : Work email, password, remember me, quick Manager & Employee demo buttons.
2. Register Page     : Account registration with role selection (Manager / Employee).
3. Dashboard         : 6 KPI Cards (Total Products, Warehouses, Suppliers, Low Stock Alert, Today's Sales, Monthly Revenue).
                       3 Chart.js Graphs (Monthly Revenue Line Chart, Stock Category Doughnut Chart, Warehouse Capacity Bar Chart).
                       Tables for Recent Sales Orders and Low Stock Warning Items.
4. Products          : Product catalog with SKU, Category, Warehouse location, Stock quantity, Price/Cost, and Status badges.
5. Warehouses        : Visual facility grid with percentage capacity progress bars, unit stock counts, and manager details.
6. Suppliers         : Vendor directory table with contact person, phone, email, rating stars, and CRUD actions.
7. Categories        : Department cards with category codes, descriptions, and item counts.
8. Customers         : B2B client accounts with lifetime spend formatted in Indian Rupees (₹).
9. Purchase Orders   : PO requisitions list with status badges (Pending, Approved, Received) & PO details modal.
10. Sales Orders     : Fulfillment list with SO status, customer address, and printable Commercial Tax Invoice (PDF) preview modal.
11. Reports          : Sales velocity analytics, CSV Excel export, and PDF printable report views.
12. Settings         : User profile, company legal GSTIN info, default base currency (INR ₹), security password change.

Rest API Endpoint Mappings Prepared in Frontend (`src/services/api.js`):
- GET /api/v1/products           : List catalog products with pagination & search
- POST /api/v1/products          : Create new inventory product
- PUT /api/v1/products/{id}      : Update inventory product
- DELETE /api/v1/products/{id}   : Remove inventory product
- GET /api/v1/warehouses         : Fetch warehouse facilities & capacity metrics
- POST /api/v1/suppliers         : Register vendor supplier
- GET /api/v1/purchase-orders    : Fetch purchase orders
- POST /api/v1/purchase-orders   : Create new purchase order requisition
- GET /api/v1/sales-orders       : Fetch sales orders
- POST /api/v1/sales-orders      : Create new sales fulfillment order
